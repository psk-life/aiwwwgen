# AIСтарт — сайт продажи AI-моделей для новичков

Продажный сайт на Flask: 8 карточек AI-моделей с кнопкой «Открыть материал»,
фильтр по категориям и страница подробного описания.

## Быстрый запуск

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```
   python app.py
   ```
3. Откройте в браузере: <http://127.0.0.1:5000>

## Структура проекта

```
app.py                  — сервер Flask и данные карточек
templates/base.html     — общий каркас страницы (шапка, подвал)
templates/index.html    — главная страница с карточками
templates/material.html — страница отдельного материала
templates/404.html      — страница ошибки 404
static/css/style.css    — стили: тёмная тема, адаптив, переходы
static/js/main.js       — фильтр карточек и уведомление «Купить»
```

## Дизайн (палитра 2026)

- Тёмный фон `#0E1117`, карточки `#151B25`
- Индиго `#7D8BFF` — главный акцент, мята `#57D6C2` — второй акцент,
  янтарь `#F2B544` — бейджи (рекомендуемые web-дизайнерами сочетания)
- Плавные переходы 0.25s, анимации отключаются при `prefers-reduced-motion`
- Компактные блоки без больших пустых промежутков

## Адаптивность

Сайт сделан по принципу mobile-first и использует сетку `auto-fit minmax`,
поэтому подстраивается под типичные разрешения 2026 года:

- Android/iOS-телефоны: 360–430 px (iPhone 390/430, Pixel 412, Galaxy 360/412)
- Планшеты: 768–1024 px
- PC/Mac: 1366, 1536, 1920, 2560 px

## Стандарты

HTML соответствует рекомендациям W3C: семантические теги
(`header`, `nav`, `main`, `section`, `article`, `footer`), `lang="ru"`,
правильная иерархия заголовков, видимый фокус, `aria`-атрибуты,
контрастность текста на уровне WCAG AA.
